


>Def (A set that has a special symbol):
>	Denote:
>	> $B_1:= S_k$
>	
>	>$B_2:=T_k$ (reference to the tournaments)
>	
>	>$B_3:=$ $X^2$ for some set $X$.
>	
>	>$B_4:=$ "$\prescript{X}{}{}\equiv$" for some set $X$.
>	
>	>$B_5:=$ "$\prescript{X}{}{} <$" for some set $X$.
>	
>	>$B_6:=$ "$\prescript{X}{}{}\le$" for some set $X$.
>	
>	>$B_7:=$ "$\prescript{X}{}{}\rightarrow$" for some set $X$.
>	
>	>$B_8:=$ $\begin{pmatrix} [k] \\ r \end{pmatrix}$ for $k,r \in \mathbb{N}$ and $r \le k$.
>	
>	$\mathcal{B}:= \left\{ B_i \right\}_{i=1}^7$

>Def (The symbol of a set that has a special symbol):
>	Let $B$ be [[#^a7b9f8|a set that has a special symbol]]. Then the special symbol of $B$ is:
>	>$\sigma$ if $B = B_1$.
>	>$Y$ if $B = B_2$.
>	>$C$ if $B = B_8$.
>	>And so on...

("Dropping the X")
>	>Note: For the relation examples, if it is clear from context what is $X$ then we can write the special symbol without notating $X$.

>Def (Short for the image of an element under function):
>	Let $A$ be some set, and $B$ "[[#^a7b9f8|a set that has a special symbol]]", let $b$ be [[#^2d6c82|the symbol of]] $B$. And let  $f: A \to B$ some function. Then we denote $\forall a \in A$ $$b_a^f:=f(a)$$

>Def (Short for the image of an element under natural projection):
>	(aka "droping the function")
>	>Let $B$ be [[#^a7b9f8|a set that has a special symbol]] and denote $b$ [[#^2d6c82|the special symbol of]] $B$. Let  $A$ some set s.t. [[there is a natural projection]] of $A$ onto $B$. Then we denote $\forall a \in A$ $$b_a:=b_a^{\zeta_{B,A}}$$
>	
>	>Note:
>	>	In the case where $B$ is one of the relations, it might not be possible to both [[#^2d6c82|drop the X from the symbol]] and drop the function from the symbol. At all times, the symbol has to be either clear from context or sufficiently denoted.
